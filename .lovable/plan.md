# Desktop preview review

## Goal
Preview ko PC (desktop) width par dikha kar workspace ka desktop layout review karna.

## Steps
- Preview desktop viewport par switch kar diya gaya hai.
- Desktop sidebar, header, aur saare sections (Order, Invoice, Extract, Rates, Calculator, History, Invoices, Customers, Sync, Admin) ka wide layout verify karna.
- Agar desktop par koi section mess ya spacing issue dikhe to woh report karein; phir us hisaab se fix plan banega.

## Technical details
- Koi code change nahi — sirf preview device desktop par set kiya gaya.
- User preview ke upar device button se khud mobile/tablet/desktop switch kar sakta hai.
